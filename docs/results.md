# Results

> A write-up of a system I built at a two-sided mental-health marketplace. It ran inside company systems, so the code isn't public.

The headline result for GTM Brain, the shared go-to-market (GTM) context layer: asset creation time down 30% (brief to first draft, self-reported by each team).

## Adoption

Adoption was voluntary. People wanted an easier way to get the information, so everyone was on board and gave feedback.

## The pilot

Before rollout, I ran a user acceptance testing (UAT) pilot. I worked with one Sales rep and one customer experience (CX) rep, and I assessed the Marketing assets myself.
- The feedback was mostly about fine-tuning the layout, and which information each output relayed.
- One round of feedback was enough.
- After that, an ongoing feedback workflow caught any issues.

## Asset creation time down 30%

- **What it measures:** the time from a brief to the first draft of an asset.
- **Who reported it:** each team created and kept its own assets, and self-reported its time savings for them.
- **When:** We saw it within a month of release.
- **Its limit:** the saving can't be split between GTM Brain and the AI tools the teams drafted with. We can't separate them; they go hand in hand.
